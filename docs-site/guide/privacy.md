# Privacy

- **Local content**: Vault files are referenced and indexed locally; content is not uploaded for core functionality.
- **Ollama**: Chat and embedding requests go to your local Ollama instance (default `127.0.0.1`).
- **Telemetry**: None by default; any future telemetry must be opt-in (see constitution).

For full wording, read `docs/adr/0004-security-privacy-boundaries.md` in the repository.
