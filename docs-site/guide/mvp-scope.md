# MVP scope (summary)

Aligned with [CONSTITUTION.md](../../CONSTITUTION.md):

- **Formats**: PDF and Markdown only; single vault.
- **Limits**: First import capped at **100** documents (batch size 20 in the sidecar).
- **UI**: Read-only graph visualization; no graph editing.
- **Retrieval**: Deterministic vector-first hybrid (no adaptive query classifier in MVP).
- **Out of scope**: Accounts, sync, plugins, cloud processing, multi-vault management, auto-updater UI.
